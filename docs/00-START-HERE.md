```

    ۳. غربال با gpt-5.4-mini: هوش مصنوعی؟ اهمیت ۱–۱۰؟ دسته؟ رویداد تکراری؟
    ۴. متن کامل منبع (Readability) → نوشتن خبر فارسی با claude-sonnet-5-5
    ۵. بررسی کیفیت (طول، فارسی بودن، ساختار، ضد تکرار) → src/content/news/<slug>.md

جمعه ۱۹:۰۰ تهران
  agent/weekly.mjs → src/content/weekly/<تاریخ شمسی>.md + متن ویدیو
```

## تصمیم‌های گرفته‌شده (کاربر، ۲۰۲۶-۱۱-۲۱)

| موضوع | تصمیم |
|---|---|
| بستر | **Astro 7 استاتیک** مثل بقیه‌ی سایت‌های مجموعه (بدون React، تقریباً صفر جاوااسکریپت) |
| محل اجرای ایجنت | **سرور فرانکفورت** (`193.36.84.146`)؛ سرور ایران به خیلی از منابع (OpenAI، Anthropic، …) دسترسی ندارد یا ۴۰۳ تحریم می‌گیرد |
| انتشار | **خودکار + بازبینی بعدی**: خبر مستقیم منتشر می‌شود؛ برای پنهان کردن، در فایل `draft: true` |
| تعداد | **هر ۴ ساعت، حداکثر ۴ خبر در هر اجرا و ۱۵ خبر در روز** (`PER_RUN`، `PER_DAY`) |
| تصویر | **کاور گرافیکی خودکار** (sharp + SVG)، بدون عکس منبع → بدون ریسک کپی‌رایت |
| هوش مصنوعی | **GapGPT** (`api.gapgpt.app/v1`، سازگار با OpenAI)؛ کلید در `secret/key.md` → `.env` |
| نوع متن | **بازنویسی** فارسی (لید، بخش‌ها، «چرا مهم است؟»)، نه ترجمه‌ی کلمه‌به‌کلمه — به خاطر سیاست scaled content abuse گوگل |
| نیم‌فاصله | **بدون نیم‌فاصله** (قاعده‌ی کارفرما برای bartar-repairer؛ `NO_ZWNJ=true`). «تراشه‌ی» → «تراشه». تغییر به `NO_ZWNJ=false` فقط روی خبرهای بعدی اثر دارد؛ خبرهای قبلی نیم‌فاصله‌ی حذف‌شده را پس نمی‌گیرند |
| فاوآیکن | **۴۸×۴۸** (`favicon.ico`) + ۹۶ و ۱۹۲ — گوگل فقط مضرب‌های ۴۸ را در نتایج نشان می‌دهد |
| مستندات | همین پوشه؛ هر تغییر مهم در `06-dev-log.md` ثبت شود |
| محل سرو | **سرور اصلی ایران** (`185.164.73.224`، nginx) + فرانکفورت به‌عنوان آینه در آینده |
| نیم‌فاصله | کاربر تأیید کرد: بدون نیم‌فاصله بماند |
| ویدیو | **کاربر خودش ضبط می‌کند** (اسکرین از صفحه‌ی هفتگی)؛ هوش مصنوعی ویدیو نمی‌سازد. جای آپلود ویدیو = کار بعدی |

## دستورها

```bash
npm run dev                         # پیش‌نمایش زنده روی localhost:4321
npm run build                       # بیلد + گارد سئو (scripts/postbuild.mjs)
npm run agent:dry                   # فقط غربال و گزارش، بدون نوشتن (هزینه ناچیز)
node agent/run.mjs --limit=2 --no-build   # نوشتن ۲ خبر بدون بیلد/دیپلوی
node agent/run.mjs --url=https://...      # نوشتن خبر از یک نشانی مشخص
npm run agent:weekly -- --no-build  # جمع‌بندی هفتگی
npm run agent:models                # فهرست مدل‌های GapGPT
node scripts/shot.mjs <dir> / /news/<slug>/   # اسکرین‌شات دسکتاپ/موبایل/تیره
```
